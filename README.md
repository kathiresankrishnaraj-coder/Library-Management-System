# Library Management System

A desktop-based Library Management System developed using Java, JDBC, and MySQL.

## Features

- Admin Login
- Book Management
- Student Management
- Issue Book
- Return Book
- Fine Calculation
- Dashboard
- Borrow Limit
- Search Books
- Purchase History
- Reservation System

## Technologies

- Java
- JDBC
- MySQL
- OOP
- IntelliJ IDEA
